# 现状与待办

（2026-10-22 整理。以前这份叫「待做」，列的是当初想做、还没做的；现在改成核对过的现状。）

---

## 一、已经做完的

**通道**
- OneBot 长连（WebSocket）+ HTTP 调用，断线指数退避重连
- 自己找 SnowLuma、自己读令牌（`node scripts/find-snowluma.mjs`）
- 图片收发：收到的图落盘、路径写进上下文；发图用 `[[img:绝对路径]]`
- 引用：能看到被引用的原文，也能引用某一条回复

**说话**
- 一句一行 = 一条消息；太长才按句末切；按字数算打字停顿
- 群里不一定回（PASS）；@/名字/关键词触发；社交状态机（活跃期、冷场试探、主动开话头）
- 垫话（干活前先应一声）可在面板配置，且她一动手就不垫

**记忆**
- 事件流（只追加）+ 蒸馏出来的记忆条目 + 待确认（先问后改）
- 每 30 分钟整理、每 6 小时体检，都能在面板看和改
- 跨房间可看 / 可分享，按房间开关

**人格**
- 三层：`core.md`（每轮）、`group.md`（只在群里）、`self.md`（每轮，她自己写）
- 三层都由桥拼进提示词（2026-10-22 修：core 之前根本没进去）
- 她想不起来自己写 `self.md` → 桥做两件事：摘情绪草稿、自由活动最后一拍做回顾

**她自己的时间**
- 自由活动：一拍一拍叫，开场那句不占额度，`<wait>/<pass>/<done>` 协议
- 自己找时间醒（随机间隔，可在面板调）
- 兴趣清单：按"久没碰"挑三件递给她

**东西**
- 表情库：收图 → 看图判定像不像表情 → 按语境打标签 → 发时挑 → 按使用频率清理
- 表情库只有一个写者（命令行走桥的接口）；保存前合并盘上条目，删除留墓碑
- 小本本：四个目录、命令行读写、面板只读、有容量上限
- 收图缓存 7 天 / 2GB 自动清理

**安全**
- 闸：三档（放行 / 记账 / 拦下问人），红线覆盖删、外发、装东西、改系统、碰密钥、写工作区外、拼代码执行
- 白名单跟着配置走（项目 + `data` + 小本本 + 她的工作区），不写死任何人的路径
- 只有 `owner.userIds` 能动电脑；别人的私聊照样回，但没有动手权限
- 发出去之前审计：遮密钥、遮群里的本机路径

**面板**
- 九个页签：自由活动 / 小本本 / 记忆 / 房间 / 工具 / 人设 / 待确认 / 事件 / 会话
- 顶上：桥状态、重启桥、唤醒 SnowLuma 并打开它的 WebUI
- 工具页能热装热卸 headless 的插件

**装起来**
- 打包成 zip、去个人数据、`check-secrets` 真能扫出东西了
- `node scripts/install-panel.mjs` 一条命令装面板（自动找 profile，不需要 pnpm）
- 桥跟着 DSH 起落，不留孤儿进程
- 首次启动自动准备 `data/`、`notebook/`、`persona/` 的骨架

- 部分群的图片发不出去（QQ 风控，`retcode 100 / result 120`），撞上就没辙
- `bsk_*` 浏览器工具只对"装好之后新建的会话"生效，老会话手里没有
- 群里"她认不认得主人"只看群名片：权限按 QQ 号认，但文字稿里只有名字，
  换个完全不同的名片她会当普通群友（主人明确说不用修）

## 四、改代码时的几条规矩

1. 所有可调的东西都走 `config`，别散在代码里
2. 表情库只有桥能写；命令行一律走 `http://127.0.0.1:3220/api/stickers`
3. 动 `persona/` 别覆盖已有文件——只补缺的
4. 改完跑一遍 `npm run selftest`、`npm run probe:gate`、`npm run probe:social`
